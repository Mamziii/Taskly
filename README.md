

# 📝 Task Manager


```
A simple and modern task management app built with React and TypeScript
```

## 🚀 Live Demo

[Watch Live Demo](https://taskly-nu-two.vercel.app/)



## 📸 Screenshot

## Features
```
➕ Add new tasks
✅ Mark tasks as completed
🗑️ Delete tasks
📋 Display all tasks
🎯 Simple and clean UI
📱 Responsive design
⚡ Fast development with Vite
🔒 Type-safe development with TypeScript

```


## 🛠️ Technologies
```
React, 
TypeScript, 
Vite,
CSS
```
